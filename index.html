Información importante

El escáner biocuántico no es una prueba diagnóstica validada para detectar enfermedades. No sustituye consultas, análisis ni evaluaciones clínicas. Sus resultados no deben utilizarse para iniciar, suspender o modificar tratamientos.

Una plataforma que puede crecer

En esta primera versión la web es informativa: todavía no recoge reservas, datos médicos ni pagos por formularios.
